# Personal Blog Website 

A responsive full-stack blog website built with React and Supabase that allows visitors to browse blog posts while providing an authenticated admin interface for creating and managing content. The project was developed to gain experience building and deploying a modern web application from frontend to backend. 

## Features 
- Responsive React user interface 
- Dynamic blog posts stored in Supabase
- Secure admin login for creating new posts
- Posts displayed in reverse chronological order
- Automatic date formatting
- Support for multi-line blog content
- Client-side routing with React Router
- Deployed using Vercel
- Version controlled with Git and GitHub

## Tech Stack
### Frontend 
- React
- JavaScript
- HTML5
- CSS3

### Backend 
- Supabase (Database & Authentication)
